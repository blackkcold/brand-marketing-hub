## A 品牌标识

### A1 形态与场景
- 蓝色字标 = 标准标识：企业与品牌传播场景优先使用；产品营销场景按需使用。
- 单色字标：产品营销创意内容；材质/工艺/成本受限（传真单、物流包装、导视等）；规定场景中与背景对比度不足；非 vivo 主场配合主办方视觉规范。
- 反白字标：大面积深色背景。

### A2 结构
- 标识是平衡整体，不得改变形状、结构和比例（结构比例参数见原件 p8：5.3x 宽、0.98x 高等）。

### A3 安全区域与最小尺寸
- 安全距离 1.5x（x 为字母 "o" 高度）。
- 最小宽度：线上端 38px / 印刷 8mm。

### A4 背景控制
- 蓝色字标按背景明度 10%–100% 分级使用（参考原件明度表）；单色/反白标识另有对应明度表。
- 合规背景：浅色干净、深色（反白）、高饱和（对比充足）；禁止：混乱背景、对比弱背景、色相过于接近背景。

### A5 工艺
- 可选烫金、烫银、击凹、击凸等平面工艺。

### A6 错误使用（九禁）
- 不得透明度、不得渐变、不得变形和裁切、不得规范外颜色、不得旋转或调整角度、不得添加干扰元素、不得轮廓和描边、不得翻转、不得改变字距。

### A7 版面应用（常规版面恒定标识宽度）
- A6=18mm，A5=25.5mm，A4=36mm，A3=51mm，A2=72mm，A1=102mm。

### A8 视觉对齐
- 居中对齐以标识主要视觉灰度区域为基准；灰度区域定义：顶部 a、底部与 "o" 底部对齐、右侧与 "o" 右侧对齐、左侧对齐原则见原件（顶部灰度 = 0.25b）。

### A9 标识位置
- A 左上角 = 一般常规平面物料默认位置（彩页、白皮书、投标书、纸质广告、网站、PPT 模板等）；
- B 右上角 = 创意特殊需求或展示场景限制；
- C 画面中心 = 视频落版、产品开机页、部分活动物料；
- D 下部居中 = 企业及印刷物料；
- E 右下角 = 仅企业内部印刷物料。

### A10 品牌联合（横版/竖版）
- vivo 主场：vivo 标识在合作方左侧；非主场可遵循对方规范或合作协议。
- 横版：分隔线高度 = "o" 高度 x，分隔线宽度 = "o" 宽度 2%；安全距离 1.5x；固定设置不随合作方变化。
- 竖版：分隔线宽度 = "o" 高度 4 倍，高度 = "o" 宽度 2%；两标识间距 = "o" 宽度，分隔线居中等距；安全距离 1.5x。
- 一事一议：为视觉平衡可基于规范微调。
- 只可使用品牌字标，不可使用特殊形式。
- 按合作方标识比例选择对应模版适配。

### A11 品牌与二级信息并置
- 横向间距 = "o" 宽度一半；纵向间距 = "o" 高度一半。
- 中文标题 vivo Sans Bold、字距 -40；中文信息 vivo Sans Demibold、字距 100。
- 只可用字标，不可用特殊形式。

### A12 特殊形式
- 蓝色徽标（特殊形式 1）：结构 2.8a/3.8b；安全距离 a；最小宽度线上 70px / 印刷 14mm。场景：成熟市场字标无法呈现最佳识别时的替代（综艺冠名、多品牌并置）；发展中/新兴市场在地品牌与产品营销（产品 KV、海报）。只可使用规范呈现的设计，不可单色或反白。背景禁与徽标颜色相近/渐变相近/冲突。
- 组合标识（特殊形式 2，品牌标识+品类信息）：仅个别新兴市场快速建立品类认知触点使用；竖版优先（最小线上 58px / 印刷 12mm），横版个别场景（最小线上 102px / 印刷 20mm）；仅竖版可作角标；避免近距离多个品牌标识同时出现；品牌认知提升后须逐步回归标准标识；海外在地语言需求联系品牌设计组。
- 全球市场标识矩阵（原件 p32–34）：总部/内销、外销成熟、发展中、新兴市场对标准标识/单色字标/蓝色徽标/组合标识的优先级不同——成熟市场单色字标优先于品牌与产品营销；发展中市场蓝色徽标优先；新兴市场蓝色徽标与组合标识按需、单色组合仅户外及视频落版。

### A13 应用场景说明
- 允许：品牌/产品/业务传播；VI 应用系统；品牌联合（书面协议约束，如 vivo×蔡司）；授权第三方传播；vivo 业务电子产品及包装（手机、平板、手表、耳机、闪充等）。
- 不允许：未列入业务的电子类（鼠标、插座、音箱）；健康安全相关非 vivo 产品（暖炉、纸巾、茶叶）；无关联物品（垃圾桶）。非 vivo 业务使用标识需法务评审。

### A14 标识书写规范
- 营销语境默认全小写 "vivo"，不受句首/名词首字母大写习惯影响；全大写语句场景方可全大写。
- 适用：平面/视频广告、公关文稿、产品包装及说明、功能水印、品牌活动、第三方平台广告、官方资讯物料等；非营销场景（工商注册、法务、财务）以当地规范为准。

- 三种色盘：色盘1 亮色调（vivo蓝+浅蓝+灰黑白）= 人文/愉悦/灵动；色盘2 蓝色调（vivo蓝+深蓝+灰黑白）= 科技/专业/信赖；色盘3 暗色调 = 智慧/领先/数字化。
- 任一配色中品牌主色为必选色；渐变和图素色调按三色调指导执行。

## C 品牌图形

- 术语：图形 Graphic / 图素 Element / 图样 Pattern。
- 基础应用图形：4 种图素（A/B 源自标识几何化；C/D 源自字母 "v" 对称演绎）按固定间距均匀排布成 4 种图样；间距参数见原件 p51–54。
- 特殊应用图形（灵动图样 Smart Pattern）：A "透镜"（四周不对称均匀渐变）、B "极光"（左右对称、上下渐变消散）；以 "i" 的菱形点为轮廓；裁切取上下左右四角区域得 "v" 字形，下角区域识别最强；任何情况保留最小单位不被切割。
- 四禁：不得改变图形间距、不得翻转、不得变形拉伸、不得规范外颜色。
- 裁切错误示例：裁出大面积圆形黑洞、切割基本单元、图形与文字信息冲突。
- 色彩仅限品牌主色及辅助色。

## D 品牌字体

- vivo Sans：9 字重（Thin/Extralight/Light/Regular/Medium/Demibold/Bold/Extrabold/Heavy）；5 大书写体系、122 语种；安装包：vivo Sans 简体（大陆）、繁体（港澳台）、Global（海外小语种，含西里尔/阿拉伯/希腊文）；系列：Compressed/Condensed/Standard/Expanded（各含 Italic）+ vivo Sans Camera。
- OpenType 特性：常规/等宽数字、营销端/系统端数字、替换型字符。
- 许可：vivo 所有，全球任何媒介可用，可分发供应商/合作伙伴；同时为免费商用字体。格式 TTF/WOFF/EOT/SVG。OS 场景字体去 vivo 开发者平台下载。
- 字重建议：Regular/Medium 正文；Demibold 二级标题/关键内容；Bold 标题/口号；Thin–Heavy 局部装饰。
- 排版参数：
  - 主标题：Bold，字距 -30，行距 1.1x 字高；
  - 副标题：Demibold，字距 -20，行距 1.2x；
  - 正文：Regular，字距 -20，行距 1.4x；
  - 注释：Regular，字距 -20，行距 1.4x；字距微调自动；
  - 信息层级字高建议整数倍比例（示例 4x/2x/x/0.5x）；段间距 ≥1.5x–2x。
- 对齐：默认左对齐；标题/品牌陈述可居中；右对齐仅遵循在地阅读方向（如阿拉伯语）。
- 图文排版：内容与文字呼应；文字区域干净、反差明显；符号与字体颜色一致。
- 非版权字体：可自行采购单次传播补充搭配，注意使用期限，不得完全替代品牌字体。

## E 企业图片

- 建筑类：画面干净简约、巧用品牌蓝、构图对称平稳；不得改变自然物颜色。
- 员工类：简约愉悦、人物灵动专注、积极情绪。
- 科技人文概念类：简洁背景、蓝色调为主、几何构图使抽象概念易理解。
- 错误示例：与企业调性不符插画、人物疲惫/沮丧/忧郁、科技冰冷无情感、背景过暗寓意不当、软件合成感过重、宗教/政治/情色等争议主题、低质量图片。

## F 排版 & 网格

- 视距分类：手持 0–0.5m（社媒数字界面）；近 2–8m（易拉宝、挂旗、门店灯箱）；远 8–16m（机场广告牌、发布会屏幕）。
- 页边距（短边比例）：手持 横 1:16~1:10 / 竖 1:18~1:12；近 横 1:14~1:12 / 竖 1:12~1:10；远 横 1:12~1:10 / 竖 1:10~1:8。
- 角标标识大小（"o" 高度占页边距 x 的比例）：手持 2/3 x；近 4/7 x；远 1/2 x；位置优先左上角。
- 网格数量为 2 的倍数（如 4x4）；以边距为基础单位 x 布局。
- 特殊形式标识作角标时参考附件 1/2（蓝色徽标、组合标识视觉规范）。

## G 应用系统

总原则：差异性、识别性、一致性、创意性、规范性（文具需符合邮政等行业标准）。

### G1 广告系统
- 分栏版面：标识/文案置于画面上识别不清时使用，文字放白色分栏区；满版版面：识别清晰时自由选择。
- 图片占比：接近正方形画面用 1/2；较宽或较竖长画面用 3/5。
- 分栏设置 4 步：视距定页边距及标识大小 → 画面比例定图片区域 → 标识安全空间定文字区域 → 放置素材。
- 线上广告避免标识重复：标识作角标（关键传播信息单独使用时）；标识与关键信息并置时附近不再放标识。

### G2 数字系统
- 标识动画建议 2–3s：动画1 渐显（3 颜色版本：蓝标白底/白标品牌色底/白标黑底）；动画2 "i" 点闪烁（2 颜色版本）。
- 社媒头像：白色字标置于品牌蓝色背景，全球各平台一致；不得改位置/大小/间距/颜色/字体；数显宽度 < 53px 时用特殊 v 字蓝标。
- 特殊 v 字蓝标：浏览器标签图标、第三方平台登录入口、v 来访登记页面。
- 公司网站：浏览器标签页 = 特殊 v 字蓝标；网站首页 = 黑色字标。
- 含二级信息头像（商城/体验店等）：各地区/业务团队不得擅自开设该类账号，一事一议。
- PPT 模板（16:9，内页正文白或黑底）：封面标题微软雅黑 40pt；封面副标题 20pt；封面其他 9pt；目录 16pt 行距 1.5；章节分隔页 32pt；内页标题 20pt；内页副标题 14pt；内页文本 12pt 行距 1.25。颜色参考 vivo 蓝/深蓝/浅蓝。
- 电子邮件 EDM：图片区域 + 可调节文字区域模板。

### G3 印刷系统
- 满版封面：标识左上角推荐 + 三种可选位置；分栏封面（企业内部刊物）：标识右下角；封底商标声明/免责声明/版权声明/地址为固定版式。
- 固定文案：维沃移动通信有限公司，中国广东省东莞市长安镇维沃路 1 号 vivo 工业园，电话 400-679-9688，邮箱 vivo@vivo.com.cn，官网 www.vivo.com。
- 内页网格：边距为基础单位 x，网格数量 2 的倍数；预留装帧宽度。
- 覆盖物：产品彩页、公司宣传册、可持续发展报告书、投标书等。

### G4 展览展示系统
- 易拉宝（800×1800mm）：标识默认左上角、尺寸基于视距；标题 vivo Sans、层级字号整数倍；图形用品牌辅助图形规范裁切。
- 户外挂旗：远距离边距 x；"o" 高度 = x；视觉对齐原则。
- 背景板三型：品牌标识墙 / 品牌联合标识墙 / 战略合作签约仪式背景板（6000×3000mm 示例）。
- 演讲台：标识上部居中；光照充足优先白底蓝字标；较暗环境做发光字（侧面不锈钢包边、正面蓝/白透光板内置发光组），优先浅色材质演讲台。
- 产品展示铭牌：正文 Regular 字距 -50 行距 1.8x。
- 展车：须出现品牌标识，避开车门处，车尾可单独加标识；图片人物脸部避开车门、文字避开门窗。
- 展台蓝色元素：构建识别/强化科技表达/丰富创意体验。

### G5 环境导视系统
- 建筑外部标识优先蓝色字标；外立面暗色或接近品牌蓝时用发光字（侧面不锈钢包边、正面白/蓝透光板）。
- 内部接待台、外部导视、导视图标素材见 VONE。

### G6 文具系统（尺寸/材质/工艺）
- 名片 90×54mm，美国保顿纸 450g，建议压印/烫印；信封 220×110mm 150g 白特种纸；信纸 297×210mm 100g 书写纸 单色 K40；传真纸 297×210mm 四色；文件袋 320×230mm 200g；文件夹 320×230×5mm 500g 专色烫亚银；便签 85×85mm 胶装；贺卡 100×160mm 烫亚银；工卡 104×65mm；红包 90×170mm 暗红触感纸 击凸烫亚金；笔记本 142×212mm PU 素皮 FSC 纸；办公用笔 132×14mm；纸袋 250×210×100mm；纸杯 85×75mm；保温杯 110×270mm 304 不锈钢；马克杯 117×115mm；vivo 访客封面图；电子邀请函；邮件签名档（模板见 VONE id=779）。

## H 品牌吉祥物

- 版权归 vivo；对内营造氛围、对外特定营销场景作辅助识别元素；前提是不影响人文科技品牌心智。
- 设计原则：仅可直接使用既有素材，不得增加新素材或编辑改动。
- 素材（基础视觉规范/节庆主题/表情包/3D）在 BPM：首页/市场营销/营销公共/吉祥物 IP 形象管理；流程含素材申请、应用审核、应用备案。
