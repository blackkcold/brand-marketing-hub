# 品牌视觉合规方法论（模块：design-spec）

> 本模块属于 brand-marketing-hub 的**品牌合规层**，不负责选择 PPT renderer。规则细则：`references/design-spec-rules.md`（主品牌 3.1 全章节）/ `references/design-spec-subbrands.md`（千镜、可持续发展）；规范原件：`assets/vivo-design-spec/`（轻量安装若缺该目录，按文末 VONE id 在线下载）。

## 方法论内核

### 一致性四锚点
任何视觉交付物（deck、KV、海报、社媒头像、签名档、导视等）都从四个锚点审查：标识（形态/位置/尺寸/安全区）、颜色（主色/辅助色/色盘）、字体（vivo Sans 字重/字距/行距）、排版（网格/页边距/视距）。

### 权威层级
VONE 最新发布 > assets 原件 > 规则细则摘录 > SKILL.md 速查。冲突时一律取上层；摘录与速查只为检索效率，不作权威。

### 版本基线（2026-08 核实）
- 主规范：《vivo品牌视觉识别规范》3.1（2025-10 更新）；2021 版 2.0 已废止；详情页内嵌 3.0 入口为旧版，禁用。
- 品牌字体 vivo Sans；旧字体 vivo type 已停止作品牌字体。
- 子品牌：千镜（2022-12）、可持续发展（2022-08）。

## 工作流

### W1 参数查询（色值/字体/尺寸/比例）
1. 先查 SKILL.md 速查；不足则读 design-spec-rules.md 对应章节（A 标识 / B 颜色 / C 图形 / D 字体 / E 图片 / F 排版网格 / G 应用系统 / H 吉祥物）。
2. 仍不足或有争议 → 打开 assets 原件对应页（中文 3.1 PDF 共 196 页）核对。
3. 答复注明来源层级（速查/细则章节/原件页码）。

### W2 设计合规审查（用户提供设计稿/物料/文案）
1. 界定适用范围：主品牌 / 千镜 / 可持续发展；市场类型（总部内销/成熟/发展中/新兴，影响标识形态优先级）。
2. 四锚点逐项核对，另查：书写规范（营销语境全小写 vivo）、联合标识比例（含合作方标识时）、九禁（透明度/渐变/变形/规范外颜色/旋转/干扰/描边/翻转/字距）。
3. 输出"符合 / 需调整 / 偏离"逐条标注 + 修改前后对照 + 依据（细则章节或原件页码）。多渠道适配（线上/印刷/户外）分别给最小尺寸与工艺建议。

### W3 出品品牌参数附着（deck/KV/签名档/邮件）
- deck：**视觉模板与故事模板分离。** 优先加载 `brand/vivo/template-manifest.json` 指向的真实 vivo reference/master 或 retained artifact template，并复用其 master、layout、theme、typography、geometry 与 recurring chrome。`references/deck-style.md` 仅在无 reference 时作为 fallback style guide；`assets/md2pptx_vivo.py` 仅为 legacy compatibility，不得作为默认 renderer。字体/色盘按当前 reference + 官方 VI 校验，合作品牌色仅可作为经验证的 accent。
- KV/海报：附色盘三色调（亮=人文愉悦灵动 / 蓝=科技专业信赖 / 暗=智慧领先数字化）、字体排版参数（主标题 Bold -30/1.1x、副标题 Demibold -20/1.2x、正文 Regular -20/1.4x）、视距→页边距→角标标识比例（手持 2/3x、近 4/7x、远 1/2x）、标识默认左上角。
- 品牌联合（vivo×ZEISS/IP/艺人）：横版分隔线高="o"高、宽="o"宽 2%；竖版分隔线宽="o"高 4 倍、高="o"宽 2%、间距="o"宽；安全距离 1.5x；vivo 主场置左；只可用字标；微调一事一议。
- 邮件签名/文具：直接用 `assets/vivo-design-spec/02-vivo邮件签名档/` 模板 docx。

### W4 版本核验与更新
1. 访问 VONE（品牌资产分类）核对四个 id 的更新日期与版本号：778=3.1 主规范、779=邮件签名档、468=千镜、361=可持续发展 EN。
2. 发现新版本：下载原件替换 assets 对应目录 → 同步 design-spec-rules.md 与 SKILL.md 速查 → 在规范清单.md 标注旧版废止。
3. 下载时跳过 .ai 源文件，除非用户明确要源文件。

## 陷阱

- 引用 3.0/2.0 旧数值；用 vivo type 作品牌字体；非版权字体替代品牌字体。
- 蓝色徽标做单色/反白应用；组合标识用于新兴市场之外；联合标识或二级信息并置使用特殊形式。
- 把摘录当权威：数值争议必须回原件或 VONE。
- 可持续发展标识脱离母品牌单独使用（原则上须与 vivo 标识并置，除非已在 vivo 标识语境）。

## 验证

- 每个数值答复带来源标注；审查结论逐条对应锚点清单并附修改建议。
- 出品附着覆盖四锚点 + 书写规范；联合标识比例复算一遍。
- 与原件冲突时以原件为准，并提示用户去 VONE 复核最新版本。
