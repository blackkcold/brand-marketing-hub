# v4.1 Synthesis Workflow

## Three-layer separation
1. **Source fact** — directly present in user material.
2. **Verified external fact** — independently researched and cited.
3. **Analysis / inference** — conclusion derived from facts; label it as judgment rather than source fact.

## Method
- Establish the decision question before building slides.
- Cluster content units by business question, not by original file order.
- Reconcile duplicated facts and surface contradictions.
- Convert raw data into a small set of decision-relevant observations.
- Build an argument chain: context → evidence → interpretation → choice → next action.
- Preserve source wording where exact wording matters; otherwise compress without changing meaning.
- Move supporting detail to appendix rather than deleting it when still decision-relevant.
- Create explicit tags for recommendation/advantage/constraint/next-step when that improves executive scanning.

## Output
Populate typed deck blocks and source_unit_ids/claim_ids; do not write directly to slide geometry here.
